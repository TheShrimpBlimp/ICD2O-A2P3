# ICD2O Assignment 2 — Project 3

## Debug the Number Guessing Game

This repository contains intentionally broken Python 3 starter code in `project3.py`. Your task is to debug it. No solution is included.

### Requirements (15 marks)

- Identify and fix the errors.
- Correct the “Too high” and “Too low” messages.
- Count the number of attempts correctly.
- Continue accepting guesses until the correct answer is entered.
- Test the completed program.
- Explain at least three errors you corrected.

Run the program with:

```sh
python3 project3.py
```

### Git Challenge 2: Fix Code Using a Pull Request (+5 marks)

1. Fork this teacher repository to your own GitHub account.
2. Clone your fork to your computer.
3. Create a branch for your fixes: `git switch -c fix-guessing-game`.
4. Identify and correct the errors in `project3.py`.
5. Test your program and record the results.
6. Commit your changes with a meaningful message.
7. Push your branch to your fork: `git push -u origin fix-guessing-game`.
8. Open a pull request from your branch to the teacher repository’s `main` branch.
9. Explain at least three fixes and your testing in the pull request description.
10. Submit your pull request link.

Do not make changes directly to the teacher’s main branch.

| Bonus criterion | Marks |
| --- | --- |
| Fork and branch created | 1 |
| Corrected code committed | 2 |
| Pull request opened | 1 |
| Clear pull request description | 1 |

### Submission

Submit the corrected `project3.py`, explanations of at least three corrected errors, screenshots demonstrating the program works, and your pull request link for the optional bonus.

### Academic integrity

All code must be written, debugged, and understood by the student. Generative AI coding assistants are not permitted. Use course notes and teacher-approved Python documentation. You may be asked to explain or modify your code in person.
